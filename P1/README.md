## GNU Zebra

It is a routing software package that provides TCP/IP based routing services.
It supports protocols such as RIP, OSPF and BGP.
It supports IPv4 and IPv6.

See [Wikipedia page](https://en.wikipedia.org/wiki/GNU_Zebra#:~:text=Zebra%20is%20a%20routing%20software,also%20supports%20IPv6%20routing%20protocols) for more info.

## Quagga

Quagga is a fork of **GNU Zebra**.
It is a network routing software suite.
Il supports protocols such as OSPF, RIP, BGP, IS-IS.

See [Wikipedia page](https://fr.wikipedia.org/wiki/Quagga_(logiciel))

## FRRouting

FRRouting is a fork of **Quagga**.
It is a network routing software suite.
It supports protocols such as OSPF, RIP, BGP, IS-IS, LDP, PIM, Babel, BFD, EVPN

See [Official website](https://frrouting.org)
